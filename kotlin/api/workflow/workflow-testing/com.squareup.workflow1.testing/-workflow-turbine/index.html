WorkflowTurbine

class WorkflowTurbine<RenderingT, OutputT>(val firstRendering: RenderingT, val firstSnapshot: TreeSnapshot, renderingTurbine: ReceiveTurbine<RenderingT>, snapshotTurbine: ReceiveTurbine<TreeSnapshot>, outputTurbine: ReceiveTurbine<OutputT>, testScheduler: TestCoroutineScheduler? = null, autoAdvanceBeforeAwait: Boolean = true)(source)

Provides independent access to three flows emitted by the workflow runtime: renderings, snapshots, and outputs. Uses shareIn to broadcast the combined rendering/snapshot flow to multiple turbines, ensuring all emissions are available to all flows without race conditions.
