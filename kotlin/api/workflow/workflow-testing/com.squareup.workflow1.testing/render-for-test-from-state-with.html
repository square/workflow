Convenience function to test a workflow starting from a specific state.

This is equivalent to calling renderForTest with testParams = WorkflowTestParams(startFrom = StartFromState(initialState)).

The state to start the workflow from.

Optional CoroutineContext to use for the test.

teardown

How to cancel and optionally await workflow runtime cleanup.

onOutput

Callback for workflow outputs.

testTimeout

Maximum time to wait for workflow operations in milliseconds.

testCase
